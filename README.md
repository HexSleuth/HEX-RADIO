## 📻 About

**HEX RADIO** is a lightweight, purely **client-side** web radio player designed to discover, stream, and explore live chart, AM, and FM radio stations from across the globe.

Built to run entirely inside any modern web browser — **no accounts, no software downloads, no external plugins, no ads**. Just open it and press play.

<div align="center">

| 🎯 **What it is** | 🚫 **What it isn't** |
|:---|:---|
| A browser-native radio tuner | A hosted streaming service |
| A global station directory explorer | A data-harvesting app |
| A chart-to-station bridge | A cookie-riddled tracking tool |
| A single self-contained HTML file | A bloated npm dependency tree |

</div>

## ✨ Features

<table>
<tr>
<td width="50%" valign="top">

### 🌍 Live Worldwide Streaming
Access **thousands** of internet radio, AM, and FM feeds from every continent — streamed directly from broadcasters to your browser.

### 📈 Top Charts Integration
View **live worldwide music charts**. Tap any chart entry to instantly find stations currently playing that song or artist.

### 🔒 Privacy First — Zero Cookies
HEX RADIO **hosts no audio**, tracks no user data, and stores no cookies. Everything runs locally in your browser.

</td>
<td width="50%" valign="top">

### 🛡️ Robust CORS Relay Pool
Ships with an **unlimited pool of 35+ public CORS relays**. Direct requests are attempted first, then automatically fall back through the relay pool if blocked by browser policy — ensuring uninterrupted access.

### 📡 HEX Sleuth FM
A built-in **virtual tuner experience** providing quick access to featured frequencies and stations.

### 🎨 Deep Customization
**34 curated palettes**, custom color pickers, and a permanently enforced, highly readable **dark mode**.

### 📱 Mobile Ready
Fully responsive layout optimized for mobile screens with **touch-friendly controls**.

</td>
</tr>
</table>

## 🛠️ Architecture & Data Sources

HEX RADIO operates **completely in the browser**. There is no backend server tracking your listening habits or processing audio.

```text
┌──────────────────────────────────────────────────────────────────┐
│                        YOUR BROWSER                              │
│                                                                  │
│   ┌────────────┐    ┌──────────────┐    ┌──────────────────┐     │
│   │ index.html │───▶│  Station     │───▶│  CORS Relay Pool │     │
│   │  (UI/UX)   │    │  Directory   │    │   (35+ relays)   │     │
│   └────────────┘    └──────────────┘    └──────────────────┘     │
│          │                   │                    │              │
│          ▼                   ▼                    ▼              │
│   ┌────────────────────────────────────────────────────┐         │
│   │        Native <audio> element  ──▶  🔊 SPEAKERS    │         │
│   └────────────────────────────────────────────────────┘         │
└──────────────────────────────────────────────────────────────────┘
                    ▲                          ▲
                    │                          │
        ┌───────────┴─────────┐     ┌──────────┴──────────┐
        │  Radio-Browser API  │     │   Chart Data Feeds  │
        │   (Station Index)   │     │  (Top Charts / Hits)│
        └─────────────────────┘     └─────────────────────┘
```

Component Source Notes
Station Index Radio-Browser API Open, community-maintained station database
Chart Data Live worldwide music charts Fetched via reliable relays and top-charts metrics
Audio Playback Original broadcasters Streams connect directly to the browser's native <audio> element
CORS Handling Public relay pool (35+) Automatic fallback chain when direct requests are blocked

No installation. No npm scripts. No dependencies. ⚡

<div align="center">

</div>

```text
1.  Open the web app  ──▶  https://hexsleuth.github.io/HEX-RADIO
2.  Browse global stations, explore the top charts, or search by genre
3.  Tap any station to start live streaming instantly
4.  Open ⚙️ Settings to customize your theme or manage active CORS relays
```

<details>
<summary><b>💻 &nbsp;Run it locally (optional)</b></summary>

<br/>

Because HEX RADIO is a single self-contained HTML file, you can run it locally with any static server:

```bash
# 1. Clone the repository
git clone https://github.com/HexSleuth/HEX-RADIO.git

# 2. Enter the directory
cd HEX-RADIO

# 3. Serve it (pick one)
python3 -m http.server 8080
# or
npx serve .
# or
php -S localhost:8080
```

Then open http://localhost:8080 in your browser.

⚠️ Note: Opening index.html directly via file:// may break CORS-dependent requests. Always use a local HTTP server.

</details>
