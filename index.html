HEX RADIO ships with 35 public CORS relays. They are used automatically whenever a direct directory request is blocked by the browser's CORS policy. All relays are unlimited and cost-free. Open the dock's globe button for the live test console.

About HEX RADIO

HEX RADIO is a single-file browser web player for chart radio stations worldwide. It streams directly from the broadcasters, indexes stations through the free Radio-Browser open API, pulls charts from top-charts.com, and routes every blocked request through an unlimited pool of cost-free CORS relays.
